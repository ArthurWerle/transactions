# Paths guard.sh refuses to edit. Format: mode|glob|reason
# mode: always = any file matching; tracked = only files already committed (new files are allowed)
always|go.sum|generated by the Go toolchain. Change go.mod and run `go mod tidy` instead, and ask first: dependency versions must not change silently.
always|server|compiled binary committed to the repo. It is build output, never source.
always|bin/*|compiled binaries. Never edit build output.
tracked|internal/migrations/*.sql|this migration is already committed and may already be applied (schema_migrations records it by filename and never re-runs it). Add a new migration file with a later date prefix instead.
